# Faharia by Lauren James Li — Final GitHub Pages Package

This is the final flat-root GitHub upload package for the Faharia book preview website.

## Author-requested revision

The following three preview pages have been removed from the public website and package:

- Table of Contents, first page
- Table of Contents, second page
- Map of Faharia

All other book-preview pages and website content remain unchanged.

## Upload

1. Delete the three obsolete files listed in `FILES-TO-DELETE-FROM-EXISTING-REPOSITORY.txt` from the existing GitHub repository.
2. Open this extracted folder.
3. Select every file inside it.
4. In GitHub, choose **Add file → Upload files**.
5. Upload all selected files directly to the repository root.
6. Commit with: `Remove Faharia contents and map pages`
7. Wait for GitHub Pages to deploy, then hard refresh the live site with `Ctrl + Shift + R`.

Do not upload the ZIP itself. Do not create an assets folder. `index.html` and all supporting files must remain together in the repository root.
